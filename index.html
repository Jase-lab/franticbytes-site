      About the board
      
            
      ========================================
      
            
      FranticBytes is a tiny retro software publisher run by SysOp LordFrazzle. The board is a pretend BBS — a handshake, a handle, a menu — in front of a real download area.
      
            
      The first product is Write65, a distraction-free drafting system for the MEGA65, with matching desktop builds for Mac, Windows, and Linux. More titles will show up here as they ship. The catalog is data-driven, so new products can be added without redesigning the board.
      
            
      This site lives at www.franticbytes.com.
